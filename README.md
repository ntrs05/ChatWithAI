# ChatWithAI — Hệ thống Chat & Voice

Ứng dụng trò chuyện văn bản realtime, gọi thoại WebRTC và tóm tắt tin nhắn bằng AI.

| Thư mục | Nội dung |
|---|---|
| [`frontend/`](frontend/) | React + TypeScript + Vite — Layered Architecture · Modular Monolith · Pub-Sub |

Xem hướng dẫn chạy và tài liệu kiến trúc tại [frontend/README.md](frontend/README.md).

```bash
cd frontend
npm install
npm run dev   # http://localhost:5173
```
